# 界面与组件约定

2026-11-12 用户已审核 Miuix 风格，2026-11-14 再次批准新版 Android 排版，并授权 Windows 沿用视觉调整。本文件约束正式界面及仓库内 UI Skill；原型使用示例数据，正式实现必须读取现有 API 并保留加载、空、失败和部分成功状态。

## 技术与来源

本仓使用 Vue 3、TypeScript、Ant Design Vue 4 和 `@ant-design/icons-vue`。Miuix 是 Kotlin Compose Multiplatform 组件库，许可证 Apache-2.0；本轮采用其设计方向，在现有 Vue 技术栈中独立实现外观和交互，不引入 Compose 运行时、不宣称安装了 Miuix Vue 包。未来迁移 Compose 只是备选方案，需要单独评估。

- [Miuix 官方组件](https://compose-miuix-ui.github.io/miuix/zh_CN/components/)
- [Miuix 接入说明](https://compose-miuix-ui.github.io/miuix/zh_CN/guide/getting-started)
- [Miuix 源码与许可证](https://github.com/compose-miuix-ui/miuix)
- [Ant Design Vue 组件](https://www.antdv.com/components/overview-cn)

| 设计参考 | 本仓组件与落位 |
| --- | --- |
| Scaffold / NavigationRail | `App.vue`、`AppNavigation.vue` 桌面侧栏 |
| NavigationBar | 手机悬浮五项底栏；首页、便笺、抽卡、日历、更多 |
| Card / SmallTitle | `a-card`、语义分组与共享圆角卡片 |

## 视觉基线

- 浅色画布 `#f5f5f5`、卡片白色；深色画布 `#101114`、卡片 `#1c1d21`。主操作蓝色，正文与按钮文字满足可读对比度。
- 卡片圆角 22–24px、控件 12–16px；布局间距按 4/8 倍数。桌面内容留白 24–40px，手机 16–20px。
- 不添加品牌大抬头、英文页码、编号导航、工业网格、黄色强调、切角或额外装饰刻度。页面只保留清楚的中文标题与真实操作。
- 主题唯一来源为 `frontend/src/composables/useTheme.ts`，公共样式在 `frontend/src/style.css`；颜色用实际已定义的 `--ant-*` / `--app-*`，不在页面另建配色。
- 浮层与主卡片层级清晰。Android 和减少动态效果时降低特效；按应用深浅主题检查，不仅检查系统主题。
- Android 保留系统自动转色适配。应用外观偏好统一保存并同步到页面；切换失败应修复状态覆盖与系统外观通知，不通过关闭系统自动转色处理。

## 页面与平台

- 首页先显示活动背景轮播及紧凑的今日签到摘要，再显示两张游戏便笺和活动提醒。首页紧凑便笺背景仅覆盖标题区，资源读数放在随主题变化的实色区；完整便笺复用既有 MAS 卡片，保留资源、每日/每周任务、异常、UID 与更新时间。五款原便笺背景随包离线可用，不能将游戏图标放大为背景，保留素材来源说明。
- 活动卡片按活动原图、大版本主视觉、原便笺默认背景依次回退；首页轮播优先大版本主视觉。加载失败或取得方形图标/小缩略图时继续回退，最终无图只保留中性底色，不以文字或游戏图标替代背景。
- 界面不展示“服务已连接”。正常加载不展示泛化的“操作成功”提示条；查询失败、部分成功及用户主动操作的实际结果仍需清楚反馈。
- 每个游戏的便笺独立通过下拉切换账号，只有一个账号时仍保留入口；首页使用紧凑控件并保留至少44px触控范围。不引入“主账号”“备用账号”称呼。
- Android 的导航、路由、打包资源与 Python 接口均不提供 MAS 管理或远端控制。桌面通过 MAS 自带 MCP 管理，入口叫“MAS 管理”。
- 抽卡统一由“获取记录”打开来源表单，Cookie／已登录账号获取仅开放明日方舟，选择森空岛账号及角色并确认后读取；其他游戏提供抽卡链接、JSON 与已支持的第三方导入，不显示未开放的账号授权入口。JSON 保留独立入口，读取的页数/时区收进高级选项；导入失败保留表单便于重试。不能搬入预览的演示数据或伪造成功状态。
- 签到结果按平台、账号、具体任务分组，汇总已完成/需处理/待确认；保留角色、UID、奖励、失败原因及执行时间，历史或无日期结果不得标成今日成功。库洛币社区任务与游戏签到分别显示。
- 跳过或关闭新手指引后持久化已处理状态；设置中允许主动重看。开启轻量模式先弹窗说明托盘唤回方式。

## Android 交互与桌面适配

- 手机五个主入口直接切换，不使用桌面侧滑过渡；“更多”为独立页面。详情仅使用约150ms的轻微进入效果，遵循减少动态效果偏好。
- 系统返回先关闭最上层选择、验证码、扫码或确认框，再返回编辑或详情页面。未保存更改先确认，取消确认后保留草稿；保存中的返回不得关闭父层。
- 账号管理与签到结果独立；账号编辑按社区展示绑定入口。手动凭据为主动展开的高级设置，保留扫码、短信、密码和手动输入能力。
- 手机多账号、角色、记录来源和外观选项从底部展开；长列表可搜索。账号排序使用上移/下移操作，桌面保留拖动。
- 日历月格使用真实活动时间并统一北京时间，选中日期再次点击可回到全部活动；无日期的活动保留在全部列表，不能猜测日期。
- 安卓界面以320/390px为基础，按钮至少44px；低高度弹层的外框、内容层与内部分组共同限制高度，由表单内容区滚动，底部操作始终可达。Windows保留侧栏与表格，沿用同一配色、卡片和表单层级。
- `scripts/verify-ui.cjs` 检查构建后的正式页面（合成HTTP响应、独立浏览器目录、禁止外部联网）；`scripts/verify-android.cjs` 验证离线打包的真实前端/引擎流程。两者均不能替代真机或真实上游验收。

## 验证

前端门禁是 `yarn lint`、`yarn typecheck`、`yarn test`、`yarn build`。检查 1440px、390px、320px 的深浅主题、所有正式路由及长文本。对弹窗检查低高度、滚动、关闭与确认操作。Android 额外构建 `vite build --mode android`，执行 `scripts/verify-android.cjs`，确认直接访问 MAS 路由也无法进入。

- Android 安全区域由原生根容器统一处理系统栏、刘海和输入法，关闭 Decor 的重复避让并消费已处理的窗口边距；网页的 `--app-safe-area-top/bottom` 为零。浏览器继续使用 `env(safe-area-inset-*)`，不按机型写死通知栏高度，不关闭 Android 自动转色。
